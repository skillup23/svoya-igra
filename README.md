# Интерактивная викторина «Своя Игра»

Локальное веб-приложение на Next.js и Tailwind CSS для проведения командной викторины «Своя Игра» на проекторе или большом ТВ.

---

## 📋 Основные возможности

- **3 команды**: динамический подсчет очков (начисление/списание баллов в один клик).
- **Редактирование названий**: возможность переименовать команды прямо в интерфейсе перед стартом.
- **3 раунда**: автоматический переход между раундами и итоговое награждение победителя с анимацией конфетти.
- **Спец-вопросы**: поддержка «Кота в мешке» и «Аукциона» с возможностью произвольного изменения номинала вопроса прямо в окне.
- **Мультимедиа**: поддержка текста, картинок и аудиофайлов.
- **Интерактив ведущего**: встроенный таймер на 20 секунд со звуковыми эффектами (Web Audio API) и полноэкранный режим.
- **Сохранение прогресса**: счет и сыгранные вопросы автоматически сохраняются в памяти браузера (localStorage) — случайное обновление страницы не сбросит игру.

## 🚀 Инструкция по запуску

### 1. Установка зависимостей (однократно)

npm install

### 2. Запуск локального сервера

npm run dev

После запуска открой в браузере:
http://localhost:3000

### 3. Режим проведения

- Нажми кнопку «На весь экран» в правом верхнем углу, чтобы скрыть вкладки браузера и элементы операционной системы.
- Для сброса всех очков и сыгранных вопросов используй круглую кнопку «Сброс игры» в шапке.

## ✍️ Инструкция по наполнению data/questions.js

Все вопросы хранятся в файле data/questions.js.

### Общая структура файла

Файл экспортирует объект gameData, состоящий из массива rounds (3 раунда). В каждом раунде:

- id — номер раунда (1, 2, 3).
- name — отображаемое название (например, "Первый раунд").
- categories — массив из 5 категорий. В каждой категории — ровно 5 вопросов.

Пример каркаса:

export const gameData = {
rounds: [
{
id: 1,
name: "Первый раунд",
categories: [
{
id: "r1_c1",
name: "Название темы",
questions: [
// 5 объектов вопросов
]
}
]
}
]
};

---

### Формат описания вопросов

Каждый вопрос имеет строго заданную схему полей:

- id (string, обязательное): Уникальный ID вопроса (например, "r1_c1_q1").
- cost (number, обязательное): Номинальная стоимость (100, 200, 300, ...).
- type (string, обязательное): Тип контента — "text", "image" или "audio".
- special (string | null, обязательное): "cat" (Кот в мешке), "auction" (Аукцион) или null (обычный).
- question (string, обязательное): Текст вопроса / формулировка задания.
- answer (string, обязательное): Правильный ответ (показывается по кнопке).
- src (string, опционально): Путь к медиа-файлу (только для "image" и "audio").

---

### Примеры добавления вопросов

1. Обычный текстовый вопрос:
   {
   id: "r1_c1_q1",
   cost: 100,
   type: "text",
   special: null,
   question: "Именно этот актер сыграл роль Нео в трилогии «Матрица».",
   answer: "Киану Ривз"
   }

2. Вопрос с картинкой:
   Положи файл в папку public/media/ (например, inception.jpg):
   {
   id: "r1_c1_q2",
   cost: 200,
   type: "image",
   special: null,
   src: "/media/inception.jpg",
   question: "Назовите фильм по этому кадру.",
   answer: "Начало"
   }

3. Вопрос со звуком:
   Положи файл в папку public/media/ (например, track.mp3):
   {
   id: "r1_c1_q4",
   cost: 400,
   type: "audio",
   special: null,
   src: "/media/track.mp3",
   question: "Угадайте, саундтрек к какому фильму звучит.",
   answer: "Интерстеллар"
   }

4. Кот в мешке:
   {
   id: "r1_c2_q3",
   cost: 300,
   type: "text",
   special: "cat",
   question: "Кот в мешке! Тема «География»: Назовите столицу Австралии.",
   answer: "Канберра"
   }

5. Аукцион:
   (При открытии ведущий может кликнуть по стоимости в шапке модалки и скорректировать ставку вручную)
   {
   id: "r1_c3_q3",
   cost: 300,
   type: "text",
   special: "auction",
   question: "Вопрос-Аукцион! Какой ученый сформулировал закон всемирного тяготения?",
   answer: "Исаак Ньютон"
   }
